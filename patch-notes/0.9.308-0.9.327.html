Epitaph · Patch Notes

Update 0.9.308–327

A plain-language look at this stretch of updates. For the full development log, see HISTORY.md.

Snapshot: ~August 3, 2026
New Item

Trial Locator — find a Trial Chamber nobody has ever set foot in

A new item, the Trial Locator, tracks down genuine, untouched Trial Chambers as you explore. Open it to see a running list of chambers it's found, each with its own themed name. From there you can pay to reveal the coordinates, or pay a bit more (scaling with distance) to teleport straight there. It's reusable, and it can also occasionally drop from defeating a Breeze.

Every chamber it finds is one that's never actually been generated or explored before — the search is specifically designed so you're never sent to the same place twice.

Plots & Permissions

A full permissions rewrite: 15 real toggles, no more boundary walls

Plot permissions were rebuilt from the ground up. Entry is now unconditional for everyone, and everything else (building, breaking, containers, doors, buttons, levers, redstone, generators, and combat against different mob types) each has its own real toggle across four categories. Repeated denied attempts on a plot now build up and result in a temporary ban from that specific plot, not a permanent kick.

Security Fix

Explosions can no longer touch a claimed plot

TNT and creeper explosions had no plot protection at all before this. Any block sitting on a claimed plot is now unconditionally protected from explosion damage.

Anti-Dupe

A known duplication trick with bundles was closed

Placing a bundle inside a hopper, dispenser, dropper, or crafter could be used to duplicate its contents. That's now blocked — the bundle is returned to whoever's using the container instead.
