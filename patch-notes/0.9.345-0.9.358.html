Epitaph · Patch Notes

Update 0.9.345–358

A plain-language look at this stretch of updates. For the full development log, see HISTORY.md.

Snapshot: ~August 5, 2026
Generators

Auto-Collect generators no longer get stuck

An Auto-Collect generator could occasionally get permanently stuck with a real product sitting uncollected on its pad, redirecting all future output into a Buffer that eventually filled up. It now recovers on its own and reliably delivers into a waiting hopper or chest.

Plots

Pause your generators and spawners independently

A new Plot Permissions option lets you pause all Generators or all Spawners on your plot separately, then turn either back on whenever you want, with everything picking up exactly where it left off.

Staff

Staff can now help manage any plot's permissions

Staff and Admin can now open and edit any plot's permissions, groups, and members directly, including plots whose owner is currently offline, through a new tool in the Staff menu.

Bug Fixes

Plot Member commands and admin tools fully fixed

  • /plot home and every other plot command now correctly work for a Plot Member, not just the original owner.
  • Admin plot search now correctly finds a Member's shared plot, not just an original owner's.
  • A repeatedly-denied action on a plot no longer racks up a temporary ban faster than intended from a single click.
